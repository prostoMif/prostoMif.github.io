PricePulse — мониторинг цен

Моя роль и ценность

Закрыл весь fullstack-цикл: архитектура, реализация, тестирование и упаковка кейса.

Для вас это означает предсказуемый процесс, прозрачную коммуникацию и результат, который можно показывать или запускать.

Проблема

Нужно следить за ценами по сотням товаров и быстро видеть, где и насколько цена изменилась.

Решение

FastAPI + SQLite для хранения истории цен, Jinja2 для серверного рендеринга, Chart.js для визуализации динамики.

Результат

Готовый инструмент: динамика по каждому товару, лучшие офферы по магазинам — основа для реального сервиса мониторинга.

Что входит в кейс

  • Каталог и фильтры
  • История цен и графики
  • Таблица офферов по магазинам
